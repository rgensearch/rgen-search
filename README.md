# RGen Search — Frontend MVP

This is the first visual prototype for RGen Search.

## Run
Open `index.html` in a browser. For PWA/service-worker testing, serve the folder with any local static server.

## What is included
- Responsive homepage
- RG brand direction
- Research search interface
- Academic-level selector
- Research / Understand / Create / Visualize sections
- Learn & Play section
- PWA manifest + service worker
- Topic chips and basic interaction
